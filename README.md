# RekBlock

A focus-first website blocker for Chrome (Manifest V3).

Block distracting sites and stay productive with:

- **Manual & category blocking** — block any domain, or toggle quick categories (News, Social, Gaming, Sports).
- **Scheduled blocking** — per-domain time windows with weekday selection, overnight support, and optional redirect.
- **Custom categories & modes** — build your own block/allow categories and switch browsing contexts with one click.
- **Focus timer** — Pomodoro and custom routines, auto-start schedules, calendar (.ics) export, break activities, and rewards.
- **Productivity dashboard** — distraction-attempt tracking, focus-time analytics, ROI estimates, and CSV/PDF export.
- **URL auto-detection** — regional/subdomain variants of blocked sites are caught automatically.
- **Password protection, dark mode, import/export, and cross-device sync.**

## Install (development)

1. Open `chrome://extensions`
2. Enable **Developer mode**
3. **Load unpacked** and select this folder
