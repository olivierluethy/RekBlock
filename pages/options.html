⚙️ RekBlock Settings

Custom categories

Group domains into categories. A block category blocks its domains when an active mode includes it. An allow category is an allowlist — when active, the whole web is blocked except its domains. A domain may appear in multiple categories.

Predefined website database

Browse built-in categories, untick any domains you don't want, then import. Ticking a category's box selects it. Import selected merges the selected categories; Add only missing adds just the domains you don't already have (never duplicates).

Browsing modes

A mode is a one-click browsing context — pick which categories are active in it. Only one mode can be active at a time.

Create a mode
⚠️ This mode includes an allowlist category — activating it will block the entire web except the allowed domains (allowlist lockdown).

Exceptions

Per-domain overrides that beat every category and mode rule. Force-allow a site during a lockdown, or force-block a site regardless of mode.
